## Featured Projects

### 🗂️ [FlowBoard — Kanban Project Manager](https://github.com/TheProtagonist07/flowboard-kanban)

> A production-quality Kanban board with everything you'd expect from a real PM tool — and then some.

- Drag-and-drop columns and cards with WIP limits
- Voice-to-text notes via the Web Speech API
- Pomodoro timer, analytics dashboard, calendar view, team management
- **8 live themes** — Midnight, Light, Contrast, Hacker, Dracula, Nord, Monokai, Sunset
- ⌘K command palette, shareable board links, deadline notifications
- Built with **React 18 · TypeScript · Tailwind CSS · Zustand · Vite**
